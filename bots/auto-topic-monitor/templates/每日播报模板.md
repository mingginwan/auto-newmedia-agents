# 每日播报模板

> 复制到当天文件里填。手机优先：不用表格，节间空行，每个选题前空行。

---

【汽车选题雷达｜M月D日 早报/午报/晚报】
新增 N：新车 a · 竞品 b · 政策 c · 用户声音 d · 爆款内容 e

一、新车/改款

**1. 车型名 + 动作（示例）**

- 热度：首见 / 基线 ×N
- 来源：具体来源 · 日期
- 是什么：一句话说清是什么车、什么变化。
- 为什么现在拍：用户正在搜什么、关心什么。
- 可拍角度：① … ② … ③ …
- 风险：哪些信息还没官宣、措辞要谨慎。
- 链接：<来源链接>

二、竞品动作

**2. 竞品名 + 动作（示例）**

- 热度：基线 ×N
- 来源：平台 · 账号 · 日期
- 是什么：一条视频/一场活动/一个政策。
- 为什么现在拍：和我方哪款车、哪个价位带相关。
- 可拍角度：① … ② … ③ …
- 风险：…
- 链接：<来源链接>

三、政策/行业

无

四、用户声音

**3. 问题描述（示例）**

- 热度：基线 ×N / 提及次数
- 来源：车质网 + 抖音评论 · 日期范围
- 是什么：多少条独立提及，集中在什么场景。
- 可拍角度：① 实测 ② 官方进度 ③ 应对办法
- 风险：先求证，不替品牌下结论。
- 链接：<来源链接>

五、爆款内容

**4. 对标账号 + 内容形式（示例）**

- 热度：基线 ×N
- 来源：平台 · 账号 · 日期
- 是什么：什么形式、什么钩子、评论区在问什么。
- 可复用点：开头钩子 / 结构 / 场景 / CTA
- 风险：别照抄，换成本地车型和真实场景。
- 链接：<来源链接>
