# 汽车选题监控 Bot：装好后的验收

按顺序做，每一步都过了才算装好。

1. 工作目录里有 `pushed.json`、`选题台账.csv`、`inbox/`、`kb/`、`周报/`。
2. 手动跑一次早间采集，当天文件夹里有结果；失败的数据源在状态文件里能看出来。
3. 让 Bot 按 `templates/每日播报模板.md` 写一次播报，确认：
   - 开头不超过两行
   - 没有表格，节间和每个选题前有空行
   - 每条有热度、来源、是什么、可拍角度、风险、链接
4. 同一选题连发两次，确认第二次不重复推；7 天后升级阶段能标「再推」。
5. 发一条打不开的链接，确认 Bot 如实说拿不到，而不是编一段总结。
6. 发一条已收过的链接，确认回复「已经收过」+ 当时主题。
7. 连续 5 天，每天至少 3 条真实选题进台账，周五复盘能看出哪些被拍/被发。
8. 周日周报能挑出 3 条可执行建议；没有新增就写「本周无新增」。
