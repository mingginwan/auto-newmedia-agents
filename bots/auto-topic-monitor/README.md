# 汽车选题监控（auto-topic-monitor）

每天早、中、晚三次播报汽车行业值得拍的新鲜事：新车、竞品动作、政策、用户声音、爆款内容。播报前一小时预跑采集，周日出一份复盘。

这个 Bot 默认用公开网页和你已登录的浏览器，不需要 API Key。

## 五类线索

| 类型 | 具体来源 | 抓什么 | 进播报的条件 | 频率 |
|---|---|---|---|---|
| **① 新车/改款** | 工信部新车申报目录；品牌官网「新车/预售」页；汽车之家、懂车帝、易车的新车频道 | 新车名、申报图、配置、预售价、上市时间 | **首见即报**，不看热度 | 每日 |
| **② 竞品动作** | 竞品官网促销页；竞品门店抖音号/视频号；汽车之家降价频道 | 官降、限时权益、置换补贴、门店活动、新话术 | 官方发布首见即报；门店内容互动 ≥ 基线 ×2 | 每日 |
| **③ 政策/行业** | 工信部、商务部、财政部、税务总局；中汽协/乘联会销量数据；地方车管所 | 购置税、补贴、限牌、智驾法规、召回、销量榜 | **首见即报**，标注影响车型和地区 | 每日 |
| **④ 用户声音** | 车质网投诉榜；黑猫投诉；抖音/小红书评论区；车主论坛 | 高频抱怨、质量问题、服务槽点、购车疑问 | 同一问题 ≥3 条独立提及，或投诉量周环比 +50% | 每日/每周 |
| **⑤ 爆款内容** | 对标账号近 7 天新发；抖音/小红书汽车话题；企业号后台视频榜单 | 选题、开头钩子、结构、评论区反应 | 互动 ≥ 账号近 30 天中位数 ×2 | 每日 |

## 选题分级

| 级别 | 定义 | 处理方式 |
|---|---|---|
| **A 级** | 当天必须知道，直接影响销售话术 | 当天进选题会，24 小时内定 |
| **B 级** | 值得跟，3 天内可拍 | 进选题池，3 天内排期 |
| **C 级** | 早期信号，先观察 | 进观察池，每周捞一次 |

分级看两条：是否影响成交话术；是否有可拍素材（图、视频、实车）。

## 热度：基线 ×N

```
热度 = 当前内容互动量 ÷ 同平台同类型内容近 30 天中位数
```

- 同平台：抖音只和抖音比，小红书只和小红书比
- 同类型：车型讲解和车型讲解比，剧情段子和剧情段子比
- 起步阈值：A 级 ≥3×、B 级 ≥2×、C 级 ≥1.5×；跑两周后按自己账号校准
- 一手源（新车申报、官降、政策、召回）首见即报，不看热度

## 每日节奏（Asia/Shanghai）

| 时间 | 例程 | 做什么 |
|---|---|---|
| 07:30 | 预跑 | 采集五类线索，写进当天文件夹，不发消息 |
| 08:30 | 早报 | 读预跑结果，发 A/B 级选题，选题会前看 |
| 11:30 | 午间预跑 | 补采上午新增 |
| 12:30 | 午报 | 只报上午新增；没有就不发 |
| 16:00 | 晚间预跑 | 补采下午新增 |
| 17:00 | 晚报 | 汇总当天全部，定次日选题 |
| 周日 20:00 | 周报 | 本周选题复盘 + 爆款归档 + 下周预判 |

## 播报格式

模板见 [`templates/每日播报模板.md`](templates/每日播报模板.md)。硬规则：

- 开头最多两行：标题 + 计数
- 不用表格；节与节之间空一行；每个选题前空一行
- 空节写「无」
- 每条必须有：热度、来源、是什么、可拍角度、风险、链接

## 选题台账

模板见 [`templates/选题台账模板.csv`](templates/选题台账模板.csv)。字段：日期、选题、类型、来源、热度、分级、状态、负责人、计划发布、实际发布、数据回收。

`pushed.json` 只记推过的选题，防止重复播报：同一选题 7 天内不重复，升级阶段标「再推」。

## 内容归档

刷到好内容，把链接发过来：

1. **查重**：收过的直接回「已经收过」+ 当时主题
2. **取原文**：抖音用 [`skills/douyin-comments`](skills/douyin-comments/SKILL.md)；小红书用你手头的登录态工具；网页用抓取。拿不到原文就如实说，不根据标题编总结
3. **结构化拆解**：按 [`templates/内容拆解模板.md`](templates/内容拆解模板.md)，含一句话总结、核心要点、可操作步骤、七要素拆解、对照工作流
4. **对照现有工作流**：哪些已在做 / 哪些没做但值得做 / 哪些无关；值得做的只给建议，人确认后再改
5. **入库**：写进 `kb/<主题>.md`，同主题合并
6. **回复**：一句话总结 + 值得做的建议

脚本七要素：视频类型、开头爆点、中间产品阐述、末尾转化设计、人物风格、配音配乐、环境布局。

## 安装

```bash
git clone https://github.com/mingginwan/auto-newmedia-agents.git
cp -R auto-newmedia-agents/bots/auto-topic-monitor /workspace/auto-topic-monitor
cd /workspace/auto-topic-monitor
cp templates/选题台账模板.csv 选题台账.csv
printf '{}\n' > pushed.json
mkdir -p inbox kb 周报
```

然后把 [`job.md`](job.md) 的岗位说明发给 Bot，按 [`routines.md`](routines.md) 建例程。

## 验收

按 [`check.md`](check.md) 逐条过。

## 边界

- 只发现、整理、起草；发布、投放、删除由人决定
- 数据源失败必须明说，别把「没采到」写成「今天没有」
- 传闻标「未证实」；引用只做学习记录，不搬运发布
- 抖音/小红书抓取出现验证码就停下叫人，不代点
